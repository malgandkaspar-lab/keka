Shorts Factory

A personal production tool for the Fliqo YouTube channel.

What it does

Shorts Factory helps the Fliqo channel produce short, factual, English-language educational videos (YouTube Shorts). For each video it researches a topic, writes and fact-checks a narration script, generates the voiceover and subtitles, assembles licensed stock footage, and renders a vertical video.

The channel owner decides in the app which videos are published and when.

How it uses YouTube

After the channel owner signs in with Google and grants access, Shorts Factory uses the YouTube Data API and YouTube Analytics API to:

  • upload finished videos and their thumbnails to the connected channel,
  • set each video's privacy status or scheduled publish time,
  • read the channel's own videos and their status, and
  • read view and engagement statistics of those videos to learn which topics and formats work best.

Shorts Factory only acts on the channel that was connected by its owner. It does not access other channels, comments, subscribers' personal data or any other Google service.

Who can use it

Shorts Factory is self-hosted and used only by the owner of the Fliqo channel. It is not offered as a public service.
